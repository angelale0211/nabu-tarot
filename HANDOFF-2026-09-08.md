## What the project is
- Trilingual (vi / en / de) tarot PWA for Nabu Tarot. Repo: `C:\Users\angel\nabu-tarot`, branch `main`. Live: https://nabutarot.com (Cloudflare Pages, deploys from GitHub `main` in about 30 s).
- Vanilla JS, no Node, no framework. `python build.py` concatenates `src/*.js` + `src/shell.html` into the committed `index.html`. Strings live in `src/strings.js` (`T()`), language picker `L()`.
- Suite: `PYTHONIOENCODING=utf-8 python test/run.py` (592 checks at v184). It loads `../index.html` in an iframe, so it tests the built page, not the source.
- Release = bump `window.APP_VERSION` in `src/main.js` AND `const CACHE` in `sw.js` to the same number, `python build.py`, run the suite, one commit, push.
